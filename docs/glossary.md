# Glossary

| Term | Meaning |
|------|---------|
| **EV2** | UI branding for ErcoView version 2 line |
| **Er-Con / IMAGE CES** | Business lineage associated with the product |
| **Proposal** | Core job/opportunity record |
| **Live** | Production database catalog `ErcoView_Live` |
| **Training** | Non-production catalog `ErcoView_Training` |
| **Local / Remote** | Which SQL host setting is used |
| **Handler / clsFrm*** | Application class that owns a form and SQL |
| **TableAdapter** | Generated DataSet component calling a fill SP |
| **Layout** | Saved DevExpress grid layout XML |
| **NOR** | Notice of readiness / related date field used in reports |
| **Hot seat** | Operational report/view over proposals |
| **SBS company** | Company dimension on proposals (`SBS_COMPANY`) |
| **git-crypt** | Transparent Git encryption for secret files |
| **Permission 1/2/3** | Admin / General / Superintendent |
| **SP** | SQL stored procedure |
| **KML** | Keyhole Markup Language for map placemarks |
